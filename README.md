# The Water Frame: a Shark Tank pitch

A one-page website pitching Richard Arkwright's **water frame** (patented 1769) to "investors", made for an Industrial Revolution Shark Tank class project.

It covers every question in the assignment:

- Who invented it, and what it was for
- How it works, with an animated cutaway diagram and a photo of a real machine
- Life before the invention, and the improvements it brought
- The market, the impact on people, and its place in the Industrial Revolution
- The ask: $250,000 for 20% of Arkwright & Co.
- Practice answers for questions the sharks might ask

## Open it

Open `index.html` in any web browser. No build step and no installs. If GitHub Pages is turned on for this repo, the site is also live at the repo's Pages address.
